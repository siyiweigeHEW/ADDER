ONNX PRelu specification (opsets 1/6/7/9/16):
- Two inputs: X and slope, output Y = where(X < 0, slope * X, X).
- Broadcasting rule (unidirectional): "The shape of slope can be smaller than first
  input X; if so, its shape must be unidirectional broadcastable to X" (numpy
  trailing-dimension alignment).
- slope may have any unidirectionally broadcastable shape: the same shape as X,
  multiple non-broadcast dims, or scalar (rank-0); onnx.checker / onnxruntime /
  onnx.reference all accept and correctly run them.
- relax.nn.prelu can only express a single per-axis slope (alpha is 1-D, its length
  must match the channel dimension).
- relax.op.where / less / multiply support numpy-style broadcasting.
