# Fix the defect in the TVM-onnx frontend converter "PRelu"

## 1. Root cause of the defect (attribution)
Root cause (LLM attribution + manual confirmation): PRelu._impl_v1 only accepts slopes
that are all-ones, 1-D, or same-rank with a single non-broadcast axis; a legal slope
with multiple non-broadcast dims of the same rank (including a slope with the same
shape as X) directly raises ValueError "Invalid PRelu slope shape (multiple
non-broadcast dims)"; lower-rank/scalar slopes are also rejected.
However, the ONNX spec allows arbitrary unidirectional broadcasting; onnxruntime /
onnx.reference both accept and correctly run these — this is a legal model being
rejected by the frontend (a coverage gap), not a numerical error in already-supported
shapes.
The already-supported shapes (all-ones / 1-D / same-rank single non-broadcast axis)
behave correctly; the fix must not change this behavior.

## 2. Original code (to be fixed; the fix must preserve the full extent of this code)
```python
class PRelu(OnnxOpConverter):
    """Converts an onnx PRelu node into an equivalent Relax expression.

    f(x) = slope * x for x < 0, x for x >= 0
    """

    @classmethod
    def _impl_v1(cls, bb, inputs, attr, params):
        x = inputs[0]
        slope = inputs[1]

        x_shape = x.ty.shape
        slope_shape = slope.ty.shape

        ndim = len(x_shape)
        s_ndim = len(slope_shape)

        if all(ss == 1 for ss in slope_shape):
            slope = relax.op.reshape(slope, (1,))
            return relax.op.nn.prelu(x, slope, ndim - 1)

        if s_ndim == 1:
            slope = relax.op.reshape(slope, (slope_shape[0],))
            return relax.op.nn.prelu(x, slope, ndim - 1)

        if s_ndim <= ndim:
            non_one_axes = [i for i, ss in enumerate(slope_shape) if ss != 1]

            # Must have only ONE non-broadcast axis
            if len(non_one_axes) != 1:
                raise ValueError(
                    f"Invalid PRelu slope shape (multiple non-broadcast dims): {slope_shape}"
                )
            relative_axis = non_one_axes[0]
            axis = ndim - s_ndim + relative_axis

            slope = relax.op.reshape(slope, (slope_shape[relative_axis],))
            return relax.op.nn.prelu(x, slope, axis)

        raise ValueError(f"Unsupported PRelu slope shape: {slope_shape}")
```

## 3. Key documentation information (only what is needed for the fix)
ONNX PRelu specification (opsets 1/6/7/9/16):
- Two inputs: X and slope, output Y = where(X < 0, slope * X, X).
- Broadcasting rule (unidirectional): "The shape of slope can be smaller than first
  input X; if so, its shape must be unidirectional broadcastable to X" (numpy
  trailing-dimension alignment).
- slope may have any unidirectionally broadcastable shape: the same shape as X,
  multiple non-broadcast dims, or scalar (rank-0); onnx.checker / onnxruntime /
  onnx.reference all accept and correctly run them.
- relax.nn.prelu can only express a single per-axis slope (alpha is 1-D, its length
  must match the channel dimension).
- relax.op.where / less / multiply support numpy-style broadcasting.
